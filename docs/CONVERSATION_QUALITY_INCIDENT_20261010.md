# Инцидент: сухой ответ, яйцо вне списка, видимые **звёздочки** в Telegram

Дата исправления исходников: 2026-10-10.
Ветка: fix/chef-warmth-direct-answers-formatting-20261010.

## Пользовательское наблюдение
Текущий живой бот написал «Отличный набор», рекомендовал крок-мадам,
хотя яйца в известном списке не были названы, повторно спросил об их наличии,
а при уточнении «при чём здесь яйца?» не ответил на прямой вопрос.
В Telegram пользователь увидел исходные "**" вокруг заголовков.

## Найденные причины в коде
1. src/sushef/bot.py:send_text отправлял сырой текст модели через
   message.answer(chunk) без Telegram parse_mode. Markdown-разметка **text**
   не отображалась жирным и оставалась буквальными символами.
2. Промпт говорил о галантности и персонализации, но не устанавливал явного
   приоритета ПОСЛЕДНЕГО прямого вопроса, разграничения "назван/не назван/нет"
   и самопроверки логических противоречий.
3. Новые настройки стиля были в функциональных ветках. Их наличие в GitHub
   НЕ подтверждает, что именно этот код развернут на сервере. Активный
   production SHA не удалось проверить без SSH/Codespaces.
4. Не было регрессионного примера такого диалога.

## Исправление
- src/sushef/telegram_format.py: экранирование произвольного HTML,
  безопасное преобразование **жирного**, *курсива*, заголовков и списков
  в Telegram HTML; осмысленное деление длинного сообщения перед разметкой;
  разрывы между прилипшими нумерованными блоками, пробелы между предложениями.
- send_text указывает parse_mode="HTML" и прикрепляет кнопки только к
  последнему сообщению.
- Persona: сначала прямой ответ; названное = подтверждено, неназванное =
  неизвестно, исключённое = недоступно; вопросы только когда существенны;
  тёплый индивидуальный отклик вместо «отличный набор»; уважение к выбранному
  стилю, форме обращения и кулинарному опыту.
- Отдельная ограниченная безопасная коррекция для точного контекстного
  случая «при чём здесь яйца?» ПОСЛЕ упоминания крок-мадам: объясняет, что
  у крок-мадам яйцо обычно сверху; признаёт путаницу и предлагает вариант
  без неуказанных яиц. Не выполняет платный запрос и не расходует квоту.
  Для иных вопросов — обычный LLM с усиленным приоритетом прямого ответа.
- По умолчанию — душевно-тёплый стиль. Уже сохранённые индивидуальные стили
  не меняются, выбор в профиле сохраняется.

## Пример корректного поведения
- При известном наборе «картофель, ветчина, сыр, сметана» первым следует
  предложить блюдо, которое действительно собирается из этих продуктов.
  Если требуется масло, соль или мука, их наличие тоже НЕ следует считать
  подтверждённым — указать условие или замену.
- На «при чём тут яйца?» дать причину: «Я предложил крок-мадам: у него
  сверху обычно яйцо. Но из Вашего списка его наличие не следовало, поэтому
  я зря увёл разговор в сторону. Для варианта с картофелем яйца не обязательны».
  Нельзя снова спрашивать о яйцах вместо объяснения.
- Комплимент уместен к интересной идее или конкретному действию пользователя,
  а не как автоматическая похвала в ответе на претензию.

## Путь к релизу
Tests (добавлены tests/test_conversation_quality.py):
- Telegram Markdown → HTML, отсутствие буквальных звёздочек,
  экранирование HTML и многочастные сообщения с кнопками;
- точное исправление вопроса про яйца с уважением к «ты/вы» и контексту;
- обработчик Telegram отвечает без расхода AI-квоты;
- правила промпта о прямом вопросе и инвентаре.

**Важно:** изменения ЗАКОММИЧЕНЫ, но полный pytest, реальная ClaudeHub
оценка теплоты ответов и выкладка в действующий Telegram-бот пока не
выполнены. Не объявлять инцидент исправленным в production, пока не проверен
активный SHA, проведён защищённый деплой и проверка реального диалога.
Нельзя запускать GitHub Actions. Ранее выявленный риск отката PostgreSQL
через Alembic 0005 также остаётся актуальным.

# Инцидент: длинный сухой ответ о горбуше вместо Rich Markdown

Дата ревизии: 2026-10-10. Целевая ветка: fix/rich-dialog-real-answers-20261010.

## Подтверждённая причина в исходниках

Режим JSON-рецепта использовал send_recipe_card с Telegram Rich Messages. **Обычный диалог** пользовался chef.answer -> send_text, минуя Rich Messages, даже если ответ содержал полноценные ингредиенты и шесть этапов приготовления. Поэтому «новые функции бота» оставались незаметными в большинстве живых разговоров. Отдельно присутствовали системные промпты, допускавшие механическое повторное знакомство, недостаточно различающуюся похвалу и вопросы о том, что человек уже уточнил.

## Исправлено

- Для всех содержательных обычных ответов free chat, rescue, ферментации и вопросов о готовке добавлен send_dialogue с `sendRichMessage(InputRichMessage(markdown=...))`. Используется Rich Markdown официального Bot API 10.3: заголовки, списки, выделение, форматированные абзацы.
- Нормализация презентации разрывает склеенные шаги вроде «15 минут.2. Овощная подушка» и размещает разделы «Продукты», «Как приготовить», «Секреты и советы». **Сырые массы, температуру, время и продукты не корректирует**.
- HTML из модельного текста экранируется. При явном TelegramBadRequest — старый форматированный HTML; при сетевой неопределённости — не отправлять повторно, чтобы не создавать дубликат.
- Длинный ответ с продуктами и двумя или более шагами предлагает кнопку «В карточку и готовить». Только после явного нажатия Сушеф делает ещё один запрос ClaudeHub, преобразует последний контекст в нормализованный рецепт, сохраняет его и открывает существующие пошаговую готовку и таймеры. Устаревшая кнопка отклоняется по короткому хэшу исходного вопроса. Действие расходует квоту.
- Усилены правила постоянных разнообразных, изысканных **обоснованных** комплиментов, индивидуальной памяти без выдумок, отказа от повторного «приятно познакомиться» в давно начавшемся диалоге, уважения к уточнению «рыба замороженная, кусками».
- Уточнена безопасность: визуальные признаки готовности не доказывают температуру; ориентир для домашнего приготовления обычной рыбы — 63 °C в толще по термометру (USDA FSIS).

## Регрессионная проверка

Новый тестовый модуль tests/test_rich_dialogue.py: структурирование шести шагов рыбного ответа, распознавание продуктов/инструкций, безопасный Markdown, Rich API вместо старого text, fallback на BadRequest, запрет повтора при неизвестном исходе, обвязка aiogram обычного режима, преобразование в карточку с учётом контекста и отказ для устаревших кнопок.

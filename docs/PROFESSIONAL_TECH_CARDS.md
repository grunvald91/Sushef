# Профессиональные технологические карты Сушефа

**Статус:** код в ветке feat/culinary-technique-cards-20261009; production ещё не проверен.

## Два уровня знаний

**Техники мастерства** (таблица culinary_techniques) содержат механизм, цель для вкуса/текстуры, управляемые признаки, типичные отклонения и исправления. В каталоге 8 карт:

- Реакция Майяра — [King Arthur Baking](https://www.kingarthurbaking.com/blog/2022/02/15/understanding-the-maillard-reaction-in-baking)
- Ореховое масло — [King Arthur](https://www.kingarthurbaking.com/blog/2020/01/08/brown-butter)
- Мягкая коагуляция яичных белков — [Exploratorium](https://annex.exploratorium.edu/cooking/eggs/gentle.html)
- Развитие клейковины — [King Arthur](https://www.kingarthurbaking.com/blog/2023/12/07/visual-guide-bread-baking)
- Складывание и отдых теста — [King Arthur](https://www.kingarthurbaking.com/blog/2023/07/31/what-does-folding-bread-dough-mean-exactly)
- Эмульсии и лецитин — [Exploratorium](https://annex.exploratorium.edu/cooking/icooks/article_5-03.html)
- Карамелизация — [King Arthur](https://www.kingarthurbaking.com/blog/2022/12/12/how-to-make-caramel)
- Пластичность масла в слоёной выпечке — [King Arthur](https://www.kingarthurbaking.com/blog/2020/08/31/why-does-butter-temperature-matter-in-pastry)

**Карты конкретных блюд** (таблица dish_process_cards) первоначально включают гаспачо и сальморехо с закладкой сырья, инвентарём, этапами, причинами, наблюдаемыми признаками и вариантами исправлений.

Источники ингредиентов:
- [Spain.info, гаспачо](https://www.spain.info/en/recipe/gazpacho/)
- [Spain.info, сальморехо](https://www.spain.info/en/recipe/salmorejo/)

В источниках указаны пропорции на четыре порции, но не указан фактический выход в граммах: сохраняется null, чисел не придумываем. Неуказанные температура и длительность этапов также не подменяются универсальными значениями. Схема допускает будущие версии и измерения.

**Проверенные факты из источника** и **наши объяснения механизмов/исправлений** явно разделены. Кулинарная техкарта сама по себе не является утверждённой производственной ТТК, сертификатом безопасности или HACCP-планом. Для ферментации нужны отдельные проверенные протоколы.

## Подключение к работе помощника

- Telegram: «🧪 Технология вкуса» → категория → механизм → контроль и исправление.
- «🌍 Кухни мира» → блюдо → «📋 Профессиональная техкарта», если она есть → адаптация под продукты пользователя.
- Подходящие карты извлекаются локально по характерным словам, до 2 за запрос. Общие слова «масло» или «еда» сами по себе не должны приводить к нерелевантным справкам.
- В новых структурированных рецептах модель может вернуть step_insights: короткие why, cue, fix для каждого важного шага. Кнопки «Почему так?» и «Как исправить?» показывают уже сохранённые пояснения без дополнительного запроса к LLM.
- Отсутствующие поля старых рецептов допустимы; если пояснения нет, помощник предлагает задать вопрос.
- Личная история, аллергены и архив не записываются в общую таблицу технологических карт.

## Что ещё требуется для полноценных ресторанных техкарт

Измеренный выход, потери/отходы, себестоимость, энергетическая ценность, проверенные режимы охлаждения/хранения, редакторское утверждение версий, связка «конкретная готовка → её результат → следующая версия рецепта». Эти поля нельзя заполнять без измерений и надёжных исходных данных.

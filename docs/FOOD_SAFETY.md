# Безопасность пищевых рекомендаций

Сушеф должен учитывать ингредиенты, аллергии и фактическую готовность пищи, а не выдавать правдоподобный текст за измеренный результат.

**Источники для будущей проверяемой базы знаний**

- [FoodSafety.gov — Safe Minimum Internal Temperatures](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures) — таблица внутренних температур приготовления, включая птицу (74 °C / 165 °F).
- [FDA — Food Allergies](https://www.fda.gov/food/food-labeling-nutrition/food-allergies) — информация об аллергенах и маркировке.

## Правила реализации

- Аллергены и исключённые продукты — только явно указанные пользователем сведения. Никогда не выводить аллергии по догадке.
- Модель не может подтверждать температурные измерения, которые пользователь не выполнил.
- При сомнении в свежести или условиях хранения не предлагать маскировку запаха, вкуса либо уничтожение токсинов готовкой.
- Для потенциально опасных ошибок ответ должен быть коротким, прямым, без шуток.
- Модель отвечает вероятностно, поэтому рецепты для аллергиков требуют дополнительной проверки состава и перекрёстного контакта.
- Текущее MVP содержит **структурную** проверку JSON, но не автоматическую фактологическую проверку всех ингредиентов и температур. Это ограничение должно быть устранено до медицински чувствительных рекомендаций.

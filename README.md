# 👨‍🍳 Сушеф — Telegram, расширенная версия 0.2

Личный су-шеф на русском языке: уважительный, добрый, остроумный ИИ-помощник для готовки, исправления блюд и планирования меню.

> **Статус:** исходники v0.2 в разработке. Подключение Telegram и ClaudeHub не проверено живым запуском. Фото реализовано как экспериментальный API-маршрут, **выключенный** по умолчанию; голос и Mini App ещё не реализованы.

## Реализовано в исходном коде v0.2

- Telegram-меню с inline-кнопками и обычным текстовым чатом;
- подбор **структурированного рецепта** из продуктов (название, ингредиенты, время, порции, шаги, примечания о безопасности);
- «Спасти блюдо», вопросы шефу и **структурированное недельное меню** (7 дней × 3 приёма пищи), сохраняемое для дальнейшего просмотра;
- пошаговый режим готовки с сохранением текущего шага;
- избранные рецепты; отдельная карточка недостающих покупок из учтённых домашних запасов;
- профиль: аллергены, исключённые продукты, вкусы, техника, порции;
- хранение диалога (не более 40 последних реплик), удаление истории и профиля;
- лимит обращений к ClaudeHub в сутки на пользователя;
- базы данных SQLite для локальной разработки и PostgreSQL для Docker;
- учёт продуктов дома (г, кг, мл, л, шт) с безопасным сопоставлением единиц;
- по меню можно выбрать завтрак, обед или ужин и получить подробный рецепт;
- перемещение назад в процессе готовки;
- оценки приготовленного блюда: великолепно, вкусно, пересолено, суховато, остро или не понравилось; последние оценки учитываются в будущих AI-подсказках;
- экспериментальная отправка фото в модель по Anthropic Messages (только с `VISION_ENABLED=true` после проверки).

**Ограничения:** автоматическая обработка фото через ClaudeHub **не подтверждена** и отключена по умолчанию. Голосовые сообщения, автоматическая синхронизация реального холодильника, пуш-таймеры, Mini App, платежи и проверенная база нутриентов пока отсутствуют. Список недостающих покупок сравнивает **точные названия продуктов** и совместимые количества; единицы без надёжного пересчёта требуют ручной проверки.

## Запуск без Docker (Python 3.11+)

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather), сохраните токен.
2. Создайте API-ключ ClaudeHub в своём личном кабинете.
3. Скопируйте конфигурацию: `cp .env.example .env`.
4. Впишите **только в локальный .env** значения `TELEGRAM_BOT_TOKEN` и `CLAUDEHUB_API_KEY`.
5. При необходимости смените `CLAUDEHUB_MODEL` на реальный доступный идентификатор модели в ClaudeHub.
6. Установите зависимости и запустите:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=src python -m sushef
```

Для Windows: `.venv\Scripts\activate`, а переменную PYTHONPATH можно задать `$env:PYTHONPATH = 'src'` в PowerShell.

**Внимание:** токены не отправляйте в чат и не коммитьте. `.env` исключён через `.gitignore`.

## Запуск в Docker с PostgreSQL

1. Заполните `.env` по примеру.
2. Запустите `docker compose up -d --build`.
3. Посмотрите `docker compose logs -f bot`.

В compose используются собственная БД PostgreSQL и один экземпляр polling. Не запускайте одновременно второй бот с тем же токеном и polling.

## Тесты и быстрая проверка

```bash
pip install -r requirements-dev.txt
python -m compileall -q src tests
pytest -q
```

Эти тесты не требуют реальных ключей и не обращаются к ClaudeHub. Отдельная ручная проверка: /start → «Мои продукты» → «Добавить» → «Что приготовить?» → рецепт → «Покупки» → «Готовим пошагово» → назад/вперёд → «Меню на неделю» → выбор конкретного блюда → /profile → /reset → /delete_me.

## Команды

`/start` — меню, `/help` — помощь, `/menu` — меню, `/pantry` — домашние запасы, `/week` — сохранённое недельное меню, `/profile` — профиль, `/reset` — очистка диалога и процесса готовки, `/privacy` — обработка данных, `/delete_me` — полное удаление сохранённых данных.

## Архитектура и качество

- `src/sushef/bot.py` — Telegram UI и маршрутизация;
- `src/sushef/chef.py` — клиент ClaudeHub и проверка структуры рецептов;
- `src/sushef/prompts.py` — личность и безопасные режимы;
- `src/sushef/models.py`, `storage.py` — профиль, диалоги, избранное, шаги;
- `src/sushef/config.py` — конфигурация;
- `tests/` — локальные тесты;
- `docs/ARCHITECTURE.md` — план последующих модулей.

API ClaudeHub: [claudehub.fun](https://claudehub.fun/), официальный клиент [Anthropic SDK](https://platform.claude.com/docs/en/api/sdks/python); Telegram-фреймворк: [aiogram](https://docs.aiogram.dev/en/latest/).

Никаких GitHub Actions по умолчанию: тесты и деплой выполняются локально или на сервере. Перед массовыми/платными запускaми необходимо явное согласование.

## Первый запуск без GitHub Actions

Если ключи занесены в **GitHub Settings → Secrets and variables → Actions**, они не появляются автоматически на сервере. Их значения доступны только заданию Actions, которое явно использует секрет. Чтобы не тратить минуты Actions, запустите бота на сервере с защищённым локальным файлом `.env`, **не коммитьте его в Git**. Подробности в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Для начальной установки без PostgreSQL используйте `docker compose -f compose.sqlite.yaml up -d --build`. Это один контейнер и постоянный том SQLite. Для штатного запуска PostgreSQL по-прежнему доступен через `compose.yaml`.

## Что важно в расширенной версии

- В `Мои продукты` можно написать по одному продукту на строку, например `рис 700 г`, `молоко 1 л`, `яйца 6 шт`. Команды «Добавить» и «Убрать» меняют записанный остаток, а не настоящий холодильник.
- `Покупки` считает недостаток только по совпадающим названиям и измерениям (кг→г, л→мл). Иные случаи помечает для проверки; нет попытки угадывать эквивалентность продуктов.
- `Меню на неделю` требует ответа модели в валидном JSON для всех 21 блюд. Сохранение плана и просмотр по дням работают на уровне кода. При смене аллергенов/исключений старый план сбрасывается.
- Если изменить аллергенные ограничения, старый рецепт и активная готовка сбрасываются. Избранные старые рецепты доступны только для ознакомления, без автоматического запуска приготовления с новыми ограничениями.
- `VISION_ENABLED=false` до подтверждения поддержки image-content через ClaudeHub. Экспериментальный фотообработчик ограничивает размер и объём обращений. Фото не сохраняются в БД, продукты автоматически не добавляются.
- Старые таблицы v0.1 сохраняются; новые таблицы `pantry_items` и `weekly_plans` создаются при запуске. До публичного релиза нужны Alembic, резервное копирование и тесты на отдельном стенде.

## Обратная связь после готовки

После рецепта или последнего шага нажмите «Оценить результат». Сушеф хранит не более 50 последних оценок пользователя в отдельной таблице и передаёт 10 последних оценок ClaudeHub для персонализации. Оценка означает субъективное впечатление, **не** объективную проверку качества и безопасности. `/delete_me` удаляет и эту историю.
